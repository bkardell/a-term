<a-term>

A pronunciation hint custom element · no dependencies

What it's for

<a-term> marks terms whose pronunciation is worth knowing — names, invented words, specialist vocabulary. By default they read as ordinary text: no underline, no tab stops, nothing to hover. Turn on Show pronunciations above (or press Alt+Shift+1) and each one shows its IPA inline, right where you are reading. Where speech is available, the IPA itself is the button that pronounces it.

Pronunciations live in a page-level list, so a name like Smaug is defined once and every occurrence can use it — whichever page or chapter a reader happens to land on.

Usage

Add pronunciations in a script:

<script type="module">
  import { pronunciations } from './a-term.js';

  pronunciations.add([
    { word: 'Smaug', pronunciation: { ipa: 'smɔːɡ', audio: 'audio/en/smaug.mp3' } },
  ]);
</script>

Mark the terms in your HTML:

<a-term>Smaug</a-term>

Terms read as plain text until pronunciations are shown. Let readers switch them on with the toggle, or set --a-term-pronunciation: inline in CSS: 

<script type="module" src="a-term-toggle.js"></script>
<a-term-toggle></a-term-toggle>

Variants, adapters, styling and the rest are under Reference at the end.

Active TTS engine

⏳ checking…
IPA is shown in pronunciation mode in all browsers. It becomes a Pronounce button when it can be spoken: with a recording (named in its pronunciation entry or by audio-src) or with an adapter. Safari's built-in speech can also be enabled (ATerm.safariSpeech = true), but it is off by default because it is unreliable in practice.

Irish names — try guessing before you switch it on

Irish mythology is full of names that look utterly impenetrable to English eyes. Niamh — daughter of the sea god Manannán — appears in many retellings, yet almost no one pronounces it correctly on first encounter. Saoirse has become familiar as a given name but still trips people up, and Cúchulainn, the great hero of the Ulster Cycle, is comfortably mispronounced for entire lifetimes. Tadhg and Aoife round out a set that looks like a keyboard walked across the alphabet.

Every entry in this demo's pronunciations names its recording (pronunciation.audio), so these play even on a page with no adapter. See Audio under Reference below.
Irish (Gaeilge) · For genuine accuracy, record with a voice that speaks Irish: word-tip-audio's Azure provider uses ga-IE-OrlaNeural; Google and Polly have no Irish voice and approximate through English phonemes. Note that Saoirse Ronan pronounces her name "SUR-sha" (rhymes with inertia); "SEER-sha" is a different regional variant.

Tolkien — one entry, every occurrence

The dragon Smaug lay upon his hoard beneath the Lonely Mountain. The wizard Gandalf had warned of its temper, but Bilbo pressed on regardless. Whatever else he did, Bilbo knew better than to wake Smaug.

Each name appears once in demo-pronunciations.js; the markup carries no IPA at all.

Right-to-left text — Genesis 1:1

בְּרֵאשִׁית בָּרָא אֱלֹהִים אֵת הַשָּׁמַיִם וְאֵת הָאָרֶץ.

“In the beginning God created the heaven and the earth.” (King James Version.) Each Hebrew word has a pronunciation entry, with Modern Hebrew pronunciation. IPA always reads left to right, so it is kept separate from the surrounding Hebrew rather than being reordered with it.

You say tomato — variants

You say tomato, I say tomato. You say potato, I say potato. You say either, I say either. You say neither, I say neither.

Here the contrast is the content, so each occurrence names its variant: variant="1" or variant="2". The ids are arbitrary keys into the pronunciations; they say nothing about the sound.

Medical terminology Always on

In clinical settings, mispronunciation can undermine a patient's confidence in their care. The heart's aorta is routinely stressed on the wrong syllable, and the blood condition thrombocytopenia defeats nearly everyone on first sight. Fibromyalgia is chronically mispronounced even by those who live with it. Knowing how to say dysphagia — difficulty swallowing — correctly, and not confuse it with dysphasia — impaired speech — is a distinction that pronunciation makes audible.

This section sets --a-term-pronunciation: inline itself, so it shows pronunciations regardless of the toggle — the property cascades like any other.

Spellcheck — sharing the words

The spellcheck custom dictionary proposal (whatwg/html#12590) lets a page tell the browser's spellchecker about its own words. The words a reader needs help pronouncing are usually the ones a spellchecker flags, so the simplest thing is to give it the same list. Both use the same shape, a word.

They are separate lists, though, and could differ: a page might accept spellings it doesn't pronounce, or pronounce words that are already spelled correctly. Passing those along anyway does no harm. 

import { pronunciations } from './a-term.js';

const entries = [
  { word: 'Niamh', pronunciation: { ipa: 'niːv', audio: 'audio/ga/niamh-niːv.mp3' } },
  // …
];

pronunciations.add(entries);
// The same words stop being flagged as misspelled.
document.spellCheckCustomDictionary?.addWords(entries.map(e => e.word));

SSML event output

Every click on an IPA button fires a a-term-ssml event. Whatever the source — pronunciations, variant or inline override — what reaches the speech engine is always a concrete <phoneme>.

Reference

<!-- 1. Optionally pick an adapter (before a-term.js) -->
<meta name="a-term-audio-url" content="audio/{lang}/{term}-{ipa}.mp3">
<script type="module" src="adapters/audio.js"></script>

<!-- 2. Load the element and your pronunciations -->
<script type="module">
  import { pronunciations } from './a-term.js';
  pronunciations.add([
    { word: 'Smaug', ipa: 'smɔːɡ' },   // ipa: shorthand for pronunciation: { ipa }
    { word: 'Niamh', pronunciation: {
      ipa: 'niːv', audio: 'audio/ga/niamh.mp3' } },   // with a recording
    // One entry per pronunciation; variant ids are arbitrary keys.
    { word: 'tomato', variant: '1', lang: 'en-US', pronunciation: { ipa: 'təˈmeɪtoʊ' } },
    { word: 'tomato', variant: '2', lang: 'en-GB', pronunciation: { ipa: 'təˈmɑːtəʊ' } },
  ]);
</script>

<!-- 3. Mark terms -->
<a-term>Smaug</a-term>
<a-term variant="2">tomato</a-term>
<a-term ipa="taɪm">thyme</a-term>

<!-- 4. Let readers turn pronunciations on (checkbox + Alt+Shift+1) -->
<script type="module" src="a-term-toggle.js"></script>
<a-term-toggle></a-term-toggle>

<!-- Options: label text, another shortcut, or just part of the page -->
<a-term-toggle shortcut="Alt+Shift+P" target="article">Show how to say names</a-term-toggle>

<!-- Or, with no script at all: any checkbox and one CSS rule -->
<input type="checkbox" id="show-pronunciations">
<style>
  :root:has(#show-pronunciations:checked) { --a-term-pronunciation: inline; }
</style>

Attributes
variant — picks a pronunciation variant by its id. Ids are arbitrary keys.
ipa — one-off override; takes precedence over the pronunciations.
lang — inherited as usual; chooses the default variant and the voice.
audio-src — URL of a recording (MP3) for this occurrence only.

Audio
A Pronounce button plays the first of these that applies:
1. audio-src on the occurrence — a recording for one place on one page.
2. pronunciation.audio in the term's entry — a recording for the term (or one variant of it), used wherever it appears. Name files however you like; relative URLs resolve against the page.
3. An adapter — builds the URL for you (the Audio adapter's template) or asks your own word-tip-audio server to speak the IPA (the Proxy adapter).
4. Safari's built-in speech, only if enabled with ATerm.safariSpeech = true (off by default; unreliable).
An ipa attribute replaces the entry's pronunciation, including its recording. Recordings are fetched once per page and cached.

Styling
::part(ipa) and ::part(button) only render when pronunciations are shown (--a-term-pronunciation: inline).
--a-term-pronunciation (none | inline) · ::part(term), ::part(ipa), ::part(button) · --a-term-ipa-color, --a-term-ipa-color-hover, --a-term-ipa-bg, --a-term-ipa-bg-hover.

Adapters
Include one adapter before a-term.js. It registers itself as window.__aTermAdapter and is picked up automatically.
Audio — plays pre-recorded MP3s from a URL template; {term}, {lang} and {ipa} are filled in for each term.
Proxy — asks your own word-tip-audio server, which speaks the IPA with Azure, Google or Polly and caches the result.
There are deliberately no adapters that call a speech service straight from the page: any API key a page can read, every visitor can read and use. Keys stay on your server. word-tip-audio is also the easiest way to make recordings in the first place: its cache uses the same {lang}/{term}-{ipa}.mp3 layout the Audio adapter reads, and its /new page creates one at a time.
